================================================================================
KEY FEATURES
================================================================================

✅ Async/Await Support
   - Fully async middleware for Express.js
   - Proper Promise-based async handlers

✅ Event Streaming
   - SSE-compliant event formatting
   - Multiple event types with IDs
   - Auto-incrementing event IDs

✅ Connection Management
   - Automatic keep-alive messaging
   - Graceful connection closure
   - Lifecycle callbacks (onConnect, onDisconnect)

✅ Error Handling
   - Error events with timestamps
   - Connection recovery
   - Automatic retry messaging

✅ Response Helpers
   - res.sendSSE() - Send events
   - res.sendError() - Send error events
   - res.sendRetry() - Request retry
   - res.sendComment() - Keep-alive
   - res.closeSSE() - Close gracefully

✅ Browser Support
   - Chrome 6+, Firefox 6+, Safari 5+, Edge 12+
   - Auto-reconnect on disconnect
   - EventSource API compatible

================================================================================
USAGE PATTERNS
================================================================================

Pattern 1: Global Middleware
   app.use(SSEMiddleware());

Pattern 2: Route-Specific
   app.get('/events', SSEMiddleware(), (req, res) => { ... });

Pattern 3: Async Handler (Recommended)
   app.post('/stream', withSSE(async (req, res, helpers) => {
     await helpers.sendSSE({ status: 'started' }, 'status');
   }));

Pattern 4: With Options
   app.use(SSEMiddleware({
     keepAliveInterval: 30000,
     onConnect: (req, res) => console.log('Connected'),
   }));

TESTING COMMANDS
================================================================================

Test with cURL:
   curl -N http://localhost:8089/events

Test with Node.js:

   eventSource.addEventListener('message', (e) => {
     console.log(JSON.parse(e.data));
   });

   eventSource.addEventListener('user_event', (e) => {
     console.log('User data:', JSON.parse(e.data));
   });
